# Palais mental — Comptabilité

Application PWA de mémorisation par palais mental pour **300 notions de comptabilité et d’analyse financière** du référentiel concours DGFiP / douanes 2026.

## Fonctionnalités

- 300 notions, dans l’ordre du lexique de référence
- domaine mental fixe en trois territoires : Maison principale, Jardin des coûts, Château financier
- pièces et loci stables pour chaque notion
- scènes mnémotechniques animées
- exploration du palais
- recherche par notion ou définition
- révision lieu → mot → définition
- statuts : à apprendre, fragile, maîtrisée
- révision espacée locale
- notes personnelles
- lecture vocale française
- dictée vocale si le navigateur la prend en charge
- fonctionnement hors connexion après première visite grâce au service worker
- installation possible comme PWA sur téléphone

## Utilisation

Ouvrir l’application depuis GitHub Pages, puis utiliser **Explorer** pour apprendre progressivement les lieux et **Réviser** pour lancer les rappels espacés.

Les données de progression et les notes sont enregistrées localement sur l’appareil.
